# React Todo Application

This is a simple and practical Todo application built with React and TypeScript. It allows users to add, complete, and delete tasks, helping to organize daily activities efficiently.

## Features

- Add new tasks with custom content
- Mark tasks as completed or incomplete
- Delete tasks from the list
- View total tasks created and tasks completed

## Technologies Used

- React
- TypeScript
- Vite (build tool)
- Phosphor Icons (for UI icons)
- UUID (for unique task IDs)

## Installation

1. Clone the repository:
   ```bash
   git clone [repository-url]
   ```
2. Navigate to the project directory:
   ```bash
   cd challenge-reactjs-todo
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Running the Application

Start the development server with:

```bash
npm run dev
```

Open your browser and go to `http://localhost:3000` (or the URL shown in the terminal) to see the app in action.
